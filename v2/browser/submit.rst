===========================
Data Submission and Updates
===========================

Introduction
============

Submit new data or update existing records using the route that suits the
size of your submission and how you prefer to work. All routes need a Webin
submission account.

What each route can submit
==========================

Check this before you choose, as some data types have only one route.

+------------------------+-------------+-----------+---------------+
|                        | Interactive | Webin-CLI | Programmatic  |
+========================+=============+===========+===============+
| Study                  |      Yes    |     No    |       Yes     |
+------------------------+-------------+-----------+---------------+
| Sample                 |      Yes    |     No    |       Yes     |
+------------------------+-------------+-----------+---------------+
| Read data              |      Yes    |     Yes   |       Yes     |
+------------------------+-------------+-----------+---------------+
| Genome Assembly        |      No     |     Yes   |       No      |
+------------------------+-------------+-----------+---------------+
| Transcriptome Assembly |      No     |     Yes   |       No      |
+------------------------+-------------+-----------+---------------+
| Template Sequence      |      No     |     Yes   |       No      |
+------------------------+-------------+-----------+---------------+
| Other Analyses         |      No     |     No    |       Yes     |
+------------------------+-------------+-----------+---------------+

Submitting data to ENA
======================

From the data submission page you can access all of our
submission services directly and access the submission guidelines
available `here <https://ena-docs.readthedocs.io/en/latest/submit/general-guide.html>`_.
