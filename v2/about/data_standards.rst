==============
Data standards
==============

ENA and INSDC reporting standards
=================================

Where appropriate, ENA requires submitted data to follow agreed reporting standards, including:

- `Feature table <https://www.insdc.org/submitting-standards/feature-table/>`_. Describes the provenance and functional annotation of nucleotide sequences.

- `Missing values <https://www.insdc.org/technical-specifications/missing-value-reporting/>`_. Rules for recording metadata that is missing or has restricted access.

- `Third PArty data <https://wwwdev.ebi.ac.uk/ena/browser/v2/about/what-ena-contains>`_. Assemblies or annotations built from existing INSDC records, captured and presented using the INSDC-agreed standards.

Community-developed standards
=================================

ENA also supports a wide range of community-developed standards, expressed as `sample checklists <https://wwwdev.ebi.ac.uk/ena/browser/v2/checklists>`_. A checklist is a defined set of minimum information that is required and validated when a sample is registered, letting submissions meet the standards agreed by a particular research community.
